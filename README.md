# אנטישימון · ANTISHIMON

מרשם ראיות של גופים שהכריזו בעצמם על חרם או עמדה נגד ישראל, ושל מקרים
שבהם נקבע ממצא רשמי בנושא אנטישמיות.

**הכלל היחיד:** רק עמדה שהגוף הצהיר עליה בעצמו, או ממצא של רשות מוסמכת.
לא שמועות, לא ״לפי מקורות״. לכל רשומה מקור שאפשר לפתוח ולבדוק.

הדרגה אומרת מה נטען. האימות אומר כמה זה מבוסס. ציר האחריות מפריד בין
החלטה של הגוף לבין אמירה של אדם שעובד בו — כדי שלא ייזרק מוצר בגלל ציוץ
של מנכ״ל.

## הרצה

אתר סטטי בלי שלב בנייה. אפשר לפתוח את `index.html` ישירות מהדיסק, או
להגיש את התיקייה מכל שרת סטטי.

## מה לא עובד כאן

חשבונות, הגשות ועדויות אישיות דורשים שרת (`backend/server.js` במאגר
המקור). בגרסה הזו הם מושבתים, והאתר עובד כמרשם קריאה בלבד.

## רישיון ותוכן

הנתונים מתועדים לפי מקורות פומביים. מצאתם שגיאה — כפתור ״בקשת תיקון״
בתוך כל רשומה. רשומה שהופרכה נשארת מסומנת ״בוטל / תוקן״ עם הסבר.
